# طلبيات — تطبيق طلبيات معمل الأكل (PWA)

تطبيق ويب عربي (يُثبَّت على الجوال من المتصفح) لإدارة طلبيات ورق العنب والملفوف للمطاعم: الطلبات بالصوت أو الكتابة، ورقة التحضير، خط التوصيل، الحسابات والديون وكشف الحساب، المصاريف، الوصفات وتكلفة الحبة، والمواد الخام المطلوبة لكل يوم. الوحدة الافتراضية: **حبة**.

## التشغيل
- `npm install` ثم `npm start` (يحتاج Node 22.13+ بسبب `node:sqlite`).
- محلياً: `./start.sh` يعيد تشغيل الخادم على المنفذ 3030.

## متغيرات البيئة
| المتغير | المعنى |
|---|---|
| `PORT` | منفذ الخادم (افتراضي 3030) |
| `DATA_DIR` | مجلد قاعدة البيانات (مثلاً `/var/data` على قرص دائم). إذا غير موجود/غير قابل للكتابة يرجع لمجلد التطبيق. |
| `DB_PATH` | مسار ملف قاعدة البيانات مباشرة (اختياري) |
| `NODE_ENV=production` | وضع الإنتاج: بدون بيانات تجريبية، وبدون رقم سري افتراضي |
| `MANAGER_PIN` | الرقم السري للمدير **عند أول تشغيل فقط**. بعدها يُغيَّر من داخل التطبيق (الإعدادات) ويُحفظ مشفّراً. |
| `SEED_DEMO=1` | تعبئة بيانات تجريبية (افتراضي في التطوير فقط) |

## ملاحظات
- في التطوير: الرقم السري التجريبي للمدير 2580، والمطاعم التجريبية 1111/2222/3333/4444.
- إعادة البيانات التجريبية: أوقف الخادم، احذف `data.db*` ثم شغّله.
- صفحة المطاعم معطّلة افتراضياً؛ تُفعّل من: المزيد ← الإعدادات.
