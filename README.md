# طلبيات

تطبيق ويب (PWA) بالعربي لإدارة طلبيات معمل الأكل اليومية للمطاعم: ورق العنب والملفوف بالحبة.

- **الرابط:** https://7gt5pfgb2k-a11y.github.io/talabiyat/
- كل البيانات محفوظة **على الجوال نفسه** (IndexedDB). لا يوجد خادم ولا حساب.
- يشتغل بدون إنترنت بعد أول فتح. الخريطة وحدها تحتاج إنترنت.

## التثبيت على iPhone
1. افتح الرابط في **Safari**.
2. اضغط زر المشاركة ⬆️، ثم اختر **«إضافة إلى الشاشة الرئيسية»**.
3. من بعدها استخدم التطبيق **من الأيقونة فقط**. بيانات Safari منفصلة عن بيانات التطبيق المثبّت.

أول مرة تفتح التطبيق بتختار رقم سري (4–8 أرقام). الرقم يُحفظ مشفّراً (PBKDF2) على الجوال، وما في رقم افتراضي.

## النسخ الاحتياطي
البيانات على الجوال فقط، لذلك:
- **المزيد ← 💾 نسخ احتياطي** بيعمل ملف JSON. احفظه في «الملفات» أو أرسله لنفسك على واتساب.
- **♻️ استعادة** بترجّع البيانات من الملف، مثلاً على جوال جديد.
- التطبيق بيذكّرك بالنسخ كل أسبوع، وبتقدر تغيّر المدة من الإعدادات.

## الملفات
| الملف | الوظيفة |
|---|---|
| `store.js` | قاعدة البيانات المحلية وكل منطق الحسابات والتوقعات |
| `manager.js` | الواجهة |
| `parser.js` | فهم الطلبية المكتوبة أو المحكية |
| `sw.js` | العمل بدون إنترنت |
| `vendor/leaflet` | الخريطة |

النسخة القديمة اللي كانت تشتغل بخادم (Node + SQLite) موجودة في فرع `server-version`.
